# Madeira

Install page for Madeira. Open https://<owner>.github.io/madeira-download/ in Safari on a registered iPhone or iPad.

To release a new build: `./publish.sh path/to/Madeira.ipa "notes"`

BCD 0.1.626: https://vuqar05.github.io/madeira-download/#v0.1.626

The BCD install manifest is `manifests/v0.1.626.plist` and points to the signed `BCD.ipa` release asset. It uses bundle ID `com.vugarahmadov.madeira`, replacing Madeira with the same ID.
